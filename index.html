ClipFyre 🔥

Turn long videos into shorts that catch.

Point ClipFyre at a 60-minute video. Get back the 5–10 moments that stand on their own — transcribed, detected, and cut automatically.

View on GitHub pip install clipfyre

How it works

  1. Transcribe — Whisper turns speech into timestamped text.
  2. Detect — segments scored for hook strength and self-containment.
  3. Cut — ffmpeg slices the winners into 9:16 shorts.
python -m clipfyre input.mp4 --out ./shorts --top 5
