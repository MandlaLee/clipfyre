Drop a video to chop

MP4, MOV, MKV — up to a few hours. Nothing uploads; this is a local-first tool.

— —

Working…

  1. Transcribe audio (Whisper)
  2. Detect the moments worth clipping
  3. Cut + crop + burn captions

      

        The browser can’t run Whisper/ffmpeg here. This demo builds a local CLI command
        using the count, length, captions, and crop settings. Lyrics mode is not supported
        by the CLI yet.
